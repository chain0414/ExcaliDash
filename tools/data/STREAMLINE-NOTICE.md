# Streamline Freehand asset source

`streamline-freehand.icons.json.gz` is a reproducible import source for 1,000
Streamline Freehand icons from `@iconify-json/streamline-freehand` 1.2.1.
Author: [Streamline](https://www.streamlinehq.com/). The source collection is
[published by Iconify](https://icon-sets.iconify.design/streamline-freehand/)
under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The importer preserves each icon's source URL and license in the server catalog.
The server changes SVG `currentColor` to a fixed dark stroke so files remain
self-contained when inserted into drawings. Published work should credit
Streamline, link its source and CC BY 4.0 license, and note the color change.
The separate Figma community file is a discovery reference; its SVG exports
are not included in this archive.
