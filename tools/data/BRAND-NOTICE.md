# Brand SVG asset sources

`brand-icons.json.gz` contains the 12 SVGs imported into ExcaliDash on
2026-09-24. The catalog stores the SVG bytes and embeds them into drawings;
`sourceUrl` is attribution metadata, not an image loading URL.

names and marks may still be subject to trademark rules; the SVG license does
not grant trademark rights.
